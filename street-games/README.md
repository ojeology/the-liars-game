# Street Games: Long Jump

An original mobile arcade athletics prototype inspired by the pick-up-and-play spirit of classic feature-phone sports games. Three long-jump attempts; your best distance counts. No account or backend.

## Play

Tap **LEFT** and **RIGHT** alternately to accelerate. Repeating the same foot does not build speed. Tap **JUMP** before the white/red takeoff line; passing it on foot is a foul. In the air tap **BOOST** when the peak prompt appears. The timing window is forgiving, but an early or late boost does not add lift. Land in the sand and repeat for all three attempts. Your personal best is stored locally on this device, when storage is available. Share uses the device share menu or copies text and a link where supported.

Desktop: A/D or left/right arrows to sprint, space to jump and boost. Pause and sound buttons are at the top. The game pauses when the browser loses focus. Sound is optional.

## Run and publish

Open `index.html` or serve this folder with `python3 -m http.server 8000`. All assets use relative paths. For the existing GitHub Pages deployment on main/root, the intended path is `/the-liars-game/street-games/`. The stadium is original AI-generated artwork in WebP; the runner, track, controls and animation are drawn in Canvas and CSS.

## Tune and test

Physics, tap speed, runway length, boost window and attempt count are in the `CONFIG` section of `game.js`. Logic and rendering are separate. Run `node --check game.js` and `node tests/test.cjs`. Real-device performance and cross-browser behaviour should be verified separately. Sound is generated by Web Audio and needs a user gesture.
